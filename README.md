# WISH 매칭 테스트

NCT WISH 멤버 매칭 테스트 — 7개 질문에 답하면 나와 어울리는 멤버를 알려주는 웹 퀴즈.

## 멤버

| 멤버 | 상징 |
|------|------|
| 유우시 (yushi) | ⭐ |
| 사쿠야 (sakuya) | 🥐 |
| 시온 (sion) | 🌷 |
| 리쿠 (riku) | 🐈‍⬛ |
| 재희 (jaehee) | 🌳 |
| 료 (ryo) | 🦭 |

## 디자인

- 폰트: 고양체 (Goyang)
- 컬러: 파스텔 네오 연두 + 스카이 액센트
- 데코: 떠다니는 4각 스파클 7개

## 실행 방법

별도 빌드 없이 정적 파일로 동작합니다.

```bash
# 로컬 서버 띄우기
python3 -m http.server 8765

# 브라우저에서 열기
open http://localhost:8765
```
